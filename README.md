# Satanism Community Gateway

A lightweight, zero-backend static prototype for profile previews and community visual identity exploration.

## Features
- **Client-Side Profile Live Preview**: Updates real-time as inputs change.
- **Dynamic CSS Themes**: Color accents toggle based on visual style selection.
- **Local Storage**: Saves profiles locally without transmitting personal data.
- **GitHub Pages CI/CD**: Ready for automatic deployment via GitHub Actions.

## Setup & Local Testing

Simply clone the repository and open `index.html` in any browser:

```bash
git clone [https://github.com/SUPRANODE00/satanism-community-gateway.git](https://github.com/SUPRANODE00/satanism-community-gateway.git)
cd satanism-community-gateway
python3 -m http.server 8000
